When fuzzing the `ci_getaddrinfo` this is a valid example of how to get the
result outside of the callback function:

```
struct ci_addrinfo *result = nullptr;
ci_getaddrinfo(channel, hostname.c_str(), nullptr, nullptr, [](void *arg, int status, int timeouts, struct ci_addrinfo *res) {
  if (status == CI_SUCCESS) {
    auto result = static_cast<struct ci_addrinfo **>(arg);
    *result = res;
  }
}, &result);  
// Cleanup
if (result) {
  ci_freeaddrinfo(result);
}
```

It is important that the `ci_addrinfo *res` in the callback is freed by the
fuzz test. Therefore an empty callback function is not valid.

The string parameter to `ci_query` must be a null terminated string. Passing
in the fuzzer input directory will cause false positive findings.

When fuzzing the `ci_gethostbyname` function the `host` parameter passed into
the callback must not be freed. This will be done automatically by c-ci.
